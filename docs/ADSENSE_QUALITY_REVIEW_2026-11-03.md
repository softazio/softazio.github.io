# AdSense 有用性の低いコンテンツ：改善監査（2026-11-03）

## 審査状況
AdSense 管理画面に「ポリシー違反が見つかりました」「有用性の低いコンテンツ」と表示。所有権確認は完了。修正・確認前に再審査を送らない。

## 確認したソース
- index.html：介護・学習・ゲーム等への導線、AdSense と GA4 の設定
- sitemap.xml：介護・福祉用具・ゲーム・金融など多数のURL
- care-notes.html：記事と各分野の案内
- care-dementia.html：認知症の情報・外部資料への入口
- care-technique.html：介護技術の動画・資料への入口
- play.html：ゲーム一覧
- about.html：運営目的と制作方針

## 改善の優先順位
1. **入口・リンク集だけのページを精査**：独自の解説、対象読者、具体的な利用場面、情報の選定理由を追加。根拠なく大量生成しない。
2. **介護記事の質**：一次資料・参照日・著者の立場・注意事項を明示。経験談と医学的事実を区別。個人情報は記載しない。
3. **ゲーム**：操作方法、難易度、アクセシビリティ、楽しみ方、独自の工夫を各紹介ページで説明。「認知症改善」等の根拠のない効能を避ける。
4. **品質**：sitemap登録URLのHTTP状態、内部リンク、スマホの表示とゲーム操作、JSエラー、重複、未完成ページを確認。
5. **信頼性**：ABOUT、CONTACT、PRIVACY、広告表記の整合性を確認。

## 再審査ゲート
- 主要ページをスマホで閲覧・操作できる
- 薄いページ・重複・リンク切れに対応済み
- 主力ページに独自の実用的説明と適切な出典がある
- 公開サイトへの反映を確認
- その後に所有者がAdSenseで「問題を修正しました」を選び再審査申請

この文書は監査開始時点の記録であり、全ページの実地検証や承認可能性を保証しない。
