# SOFTAZIO LIFE 125 — 開発仕様（レビュー用）
作成日: 2026-10-29
状態: 仕様案。main未変更・公開未実施。

## 目的
「お金の備え」から開く独立ページ life125.html。本人の年齢上限（最大125歳）を指定し、家族イベント・年間資産推移・過去のクロニクルを俯瞰する。既存finance-simulator.htmlは維持。

## MVP（第1段階）
- 本人と家族（人数自由）の名前またはニックネーム、続柄、生年月日、任意の開始・終了日
- 本人の終了年齢を50〜125歳で選択（開始年齢より低い値は不可）
- 年/月のカレンダーと年表。家族イベントを日付・分類・金額・繰り返し・メモ付きで追加・編集・削除
- 現預金、月収、月支出、臨時収支、ローン残高・金利・返済、退職年齢、年金開始年齢と月額
- NISAは保有残高、拠出額、運用利回り、取崩し、非課税制度の制約を別管理。制度上の限度額等は根拠と基準日を明記し、制度変更に追随できる設定
- 物価上昇率、給与上昇率、運用利回りを独立設定。名目残高と基準年価格での実質価値を併記
- 月次計算から年次集計を生成し、家計現金・投資残高・負債・純資産を区別。マイナス残高と資金ショート時点を表示
- ベース/楽観/慎重の3シナリオ比較。過去クロニクルは任意で記録し予測計算と分離
- ブラウザ内の保存、JSONエクスポート/インポート、全消去、サンプルデータ。保存時の共有端末注意を明示

## 計算と表示の注意
- 生年月日から暦年と年齢を算出し、月次の収支を処理。年金受給開始月・退職月・イベント月を反映
- NISA利回りは仮定であり将来の収益を保証しない。税制・社会保険料・公的年金額は推定条件を明示し、最新一次情報に照らして別途レビュー
- 年金額は利用者入力を基本とし、既存計算機のロジックを無断流用・変更しない
- インフレ調整は基準年からの累積物価指数を用いる。年齢125歳までの予測は仮定の長期延長であり精度を保証しない
- 高コントラスト、キーボード操作、スマホ表示、入力ラベル、図の代替表を備える
