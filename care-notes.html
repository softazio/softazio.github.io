FIELD NOTES

介護の現場

CARE NOTESの中心テーマ。現場で生まれる問いを、一般化して整理します。

CARE NOTE / THEME

支える側のつもりが、学ばされている。

援助する側が一方的に与えるのではなく、相手のペース、言葉、沈黙、生活歴からこちらも学び続けるという視点。

CARE NOTE / THEME

“頑張る”より、“整える”。

最大出力で動き続けるのではなく、順序、姿勢、道具、声かけ、タイミングを整えるという考え方。

CARE NOTE / THEME

徳と介護。見えない仕事について。

記録や評価に残りにくい小さな配慮と、チーム全体の流れとの間でどう判断するかを考えます。

STOCK BOX

仕事の「負」を、次の「正」へ。

注意されたこと、うまくいかなかったこと、職場で引っかかったことをストックし、後から「事実 → 感情 → 原因 → 次の一手 → 学び」の順で整理していきます。ここは医療的な診断や治療を行う場所ではなく、仕事上の出来事を振り返るための整理スペースです。
